FPL Draft Board

Step by step, Windows / PowerShell. You never need a league ID.
1. One-time setup 2. Before each draft 3. During the draft 4. What good looks like 5. After Troubleshooting Commands

Part 1

One-time setup
1.1 · Check Python
py --version

Expect Python 3.12.x or similar. If you get "not recognized":

winget install Python.Python.3.12

Close PowerShell, reopen, try again.

Use py, never python3
python3 does not exist on Windows. If py fails but python works, use python.
1.2 · Unzip somewhere permanent

Not Downloads. Something like C:\Users\dcane\fpl-draft.

1.3 · Only if you want the Excel version
py -m pip install openpyxl

The HTML board needs nothing installed.

Part 2

Before each draft · about 3 minutes
2.1 · Open PowerShell in the folder
cd C:\Users\dcane\fpl-draft
2.2 · Pull fresh player data
py draft.py --deep --teams 10 fetch

Set --teams to your real league size. It decides where replacement level sits, which drives every number downstream. --deep adds last season's history, takes a minute or two, and is worth it.

  • It printed a player count in the hundreds
  • It printed a count of players with last-season history
If it printed 0 players, stop
The Draft game isn't serving data. Nothing downstream will work.
2.3 · Clear old draft state
py draft.py reset

Do this after every mock draft. Skip it and the board thinks 150 players are already gone.

2.4 · Build the board
py draft.py --teams 10 --slot 4 export

--slot is your pick number in round one. Don't know it yet? Put anything, there's a dropdown in the page.

Optionally, for prep and note-taking:

py draft.py --teams 10 export-xlsx
2.5 · Open draft-board.html

Double-click it in File Explorer.

  • No yellow "Sample data" banner. If you see one, you exported from the offline test set. Redo 2.2 then 2.4.
  • Player names are real footballers
  • Header shows the right league size and your slot

Part 3

During the draft
The whole loop
Someone picks, you type their name, you hit Enter. That's it.
SituationWhat you do
Someone else drafted a player Type a few letters, press Enter
You drafted a player Type his name, press Shift+Enter
Made a mistakeClick Undo
Want to see only defendersClick DEF
Start overClick Reset

The cursor stays in the search box, so you can keep typing as picks fly.

When it's your turn, read the TAKE NOW panel. Player, the reason in one sentence, three alternates. In a hurry, that's all you need.

When you have a moment, check two columns before committing:

ColumnMeaning
Lasts Chance he survives to your next turn. under 30% take him now or lose him. over 75% you can wait.
Market FPL's own rank plus a coloured offset. Green +60 means the field rates him 60 spots lower than your board, so you can probably wait a round and still get him.
The one override worth knowing
If the top recommendation is green on both columns and someone just below is red on both, take the red one. You'll still get the green player later. This is the single most valuable judgement call the tool sets up for you, and it's the reason those columns exist.

Trust tiers over small VORP gaps. A 4-point VORP difference is inside the noise of preseason projections. A tier break is a real cliff.

Your picks live in the address bar, so a refresh won't lose the draft. Bookmark the URL mid-draft for a checkpoint.

Part 4

What good looks like

Roughly what the maths produces, so you can sanity-check it live.

RoundsUsually
1-4Midfielders and forwards. This is where the VORP cliffs are.
5-9More attackers, your first genuine defenders
10-13Defenders, especially high-DEFCON ones, first keeper
14-15Second keeper, upside picks, promoted-team fliers

If the board tells you to take a keeper in round 3, something is wrong with the data. Check for the sample-data banner.

Promoted teams
Never draft a Coventry, Ipswich or Hull player before round 11. Their whole value is that they're free. One exception: Leif Davis (Ipswich, LB, 18 assists in the promotion season) is worth a round or two earlier. Full detail in SLEEPERS.md.

After the draft
  • py draft.py reset if you'll run another draft
  • Keep SLEEPERS.md handy for early-season waivers

Troubleshooting

When something breaks
SymptomFix
'python3' is not recognized Use py. python3 is Mac/Linux only.
unrecognized arguments: --deep Old copy. Flags now work before or after the subcommand. Re-unzip the latest bundle.
fetch printed 0 players The Draft game isn't serving data yet. Nothing works until it does.
Yellow "Sample data" banner You exported from the test set. Run fetch, then export again.
Excel shows #NAME? in VORP Your Excel predates 2019 and lacks MINIFS. Use the HTML board.
Everything says 0 players left You forgot py draft.py reset after a mock draft.

Reference

Every command
py draft.py --deep --teams 10 fetch      # pull data, once per draft day
py draft.py --teams 10 --slot 4 export   # build the HTML board
py draft.py --teams 10 export-xlsx       # build the Excel board
py draft.py reset                        # wipe draft state
py draft.py --slot 4 best                # recommendation in the terminal
py draft.py live                         # interactive terminal mode
py draft.py board DEF -n 30              # top 30 defenders
You never need a league ID
Player data comes from draft.premierleague.com/api/bootstrap-static, which is public and needs no login. A league ID only unlocks your own league's standings and rivals' rosters, and you're tracking those by hand.
